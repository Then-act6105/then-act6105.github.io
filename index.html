📌 What Is This Application?

This application is a research tool that compares 7 different CNN architectures (Convolutional Neural Networks) for recognizing human facial emotions like happiness, sadness, anger, surprise, fear, disgust, and neutral expressions.

It uses two different approaches:

  • 🧩 Generic facial regions – The whole face is processed.
  • 🎯 Action Unit-aligned regions – Specific facial zones based on FACS (Facial Action Coding System) are analyzed individually.

The application also explores feature fusion techniques and 3D convolutions to improve accuracy. All models were tested on two popular datasets: RAF-DB and CK+.

✨ Awesome Features You'll Find

  • 🎛️ 7 CNN Architectures – Compare models like ResNet, VGG, and custom designs to see which performs best for emotion detection.
  • 🧠 Action Unit (FACS) Regions – Detect emotions by analyzing specific parts of the face (eyes, mouth, cheeks) tied to facial muscle movements.
  • 🔗 Feature Fusion – Combine data from different facial regions for more accurate predictions.
